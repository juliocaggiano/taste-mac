# Taste for Mac

This repository holds the downloads of Taste for Mac. The app's source code is private.

**[Download the latest version](https://github.com/juliocaggiano/taste-mac/releases/latest/download/Taste.dmg)**

- Needs macOS 13 or later, on an Apple silicon or Intel Mac.
- Signed with a Developer ID and notarized by Apple.
- To install, open the disk image and drag Taste to Applications.

Taste on the web: https://taste-capstone.vercel.app
